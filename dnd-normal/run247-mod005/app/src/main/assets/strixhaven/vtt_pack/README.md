# Strixhaven VTT — Assets individuais

Pacote preparado para integração no app.

- Mapas base: 7.
- Folhas-fonte transparentes preservadas: 28.
- Recortes individuais PNG com transparência: 586.
- Cada recorte vem de um componente visual isolado detectado pela transparência.
- `manifest.csv` e `manifest.json` mapeiam cada asset ao arquivo-fonte.
- `indices/` contém páginas de índice visual para localizar rapidamente os recortes.

Observação: elementos de rota tracejada podem aparecer como segmentos individuais, deliberadamente, para permitir composição dinâmica no mapa.
