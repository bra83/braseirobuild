# AoR Ace/Gunner R2C2 source review

- Position: `ace:gunner:r2c2`, FIRMEZA (Brace), printed page 68 of *Star Wars: Age of Rebellion Core Rulebook*.
- Source: official AoR Core Rulebook PDF, Google Drive ID `1w2M6f7R_dzaaHk6Q6R8Y7TIqAYM2MJIq`; SHA-256 `25087E5B43C289EF556A365EEC1177123055DFB75C3ECF03481CD66044CACE50`. The Ace: Gunner tree is printed p.68 (physical PDF p.69).
- Source semantics: once per round, Brace is used as a maneuver to reduce Setback dice from the character's next action when environmental circumstances cause them, up to the talent rank. The text identifies the next action and environmental cause; it does not limit that action to personal skill or weapon checks. This proof passes a typed environmental Setback count into a vehicle weapon action and keeps defense/firing Setbacks intact.
- Deterministic consumer: `rules/talents.mjs:247-253` derives the rank from source-backed Brace purchases and caps removal by environmental Setback. `core/controller.mjs:5621-5665` prepares Brace using either the personal-combat maneuver budget or the active vehicle-combat maneuver budget; a second vehicle maneuver follows the existing system-strain/action exchange. `core/controller.mjs:7161-7260` consumes it on the next vehicle attack, adds only the remaining environmental Setbacks through `vehicles.mjs:877-902`, records the effect, and persists the consumed state.
- UI and bridge: main UI `index.html#braceButton` and `ui/app.mjs:829-841,1356-1358` prepare Brace and collect a separate GM-declared vehicle environmental setback amount; the R46 P98 vehicle screen in `r46/final-runtime.js:1910-1917` exposes the same preparation and typed setback input. Both call the deterministic game bridge.
- Exact consumer test: `tests/uae-aor-individual-position-proofs.test.mjs`, `AoR p.68 Ace/Gunner R2C2 Brace buys exact node, removes environmental setback from vehicle attack and survives three reloads`. It buys the exact R2C2 slot after connected prerequisites, confirms its p.68 receipt, spends the first vehicle maneuver and pays 2 system strain for the second, restores the pending source receipt three times, rejects malformed input without consuming it, then verifies a rank-1 reduction against an otherwise identical attack. Three fresh controllers confirm the consumed receipt/effect remains persisted.
- Prior personal-action tests: `tests/uae-aor-brace-talent-authority.test.mjs` continues to verify skill/weapon consumers, non-environmental setback preservation, expiration, and bridge/main UI wiring.
- Full per-file regression evidence: `evidence/AOR_GUNNER_R2C2_FULL_REGRESSION_20261017/summary.json`, raw TAP logs for every test file including all six stress files.
- Scope: this review certifies only Gunner R2C2. Other AoR positions retain their individual statuses; catalog presence alone does not certify them.
