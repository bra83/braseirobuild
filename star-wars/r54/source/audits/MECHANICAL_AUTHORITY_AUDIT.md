# Mechanical authority audit: recovered P244 + WIP5

**Audit type:** read-only source and existing-test inspection. No tests were run and no code was changed for this audit.

**Decision rule:** a claim is marked CERTIFICADO only when the inspected evidence covers source and effect, controller/UI path, persistence/reopen, and an existing test assertion for the same path. Otherwise it is PENDENTE. A test file is evidence that an assertion exists; it is not evidence that the test passed in this audit run.

## Summary

The inspected architecture places most player-facing mechanics behind GameController methods that call deterministic rule modules, then commit typed state events through the local repository. LocalStorageRepository validates on save and migrates/validates on load. Several existing tests assert persistence/reopen for selected paths. This supports a design claim, not a blanket runtime certification of every game subsystem.

No domain below meets all required evidence in this read-only pass, so no domain is certified here. Significant implementation paths and test targets are listed to make the remaining checks actionable.

## Gemini / Barbara proposal boundary

1. `master/provider.mjs` builds a structured request with an explicit instruction that local deterministic executors own rules, rolls, inventory and consequences, while the remote provider is limited to a proposal. It also says provider/network failure must not mutate the campaign and tells it to use catalog-backed request/reward shapes rather than writing inventory directly.
2. `core/uiBridge.mjs:2174-2238` routes player intent through the remote request path, checks the Barbara/Gemini context shape and rejects sourceRuleIds absent from the recovered rule set before sending the proposal to `GameController.requestMasterTurn`. The catch path reports failure and preserves campaign state. The host Gemini request is a transport/proposal bridge (`core/uiBridge.mjs:29-88`), not a direct state API.
3. `core/controller.mjs:927-959` validates the response, applies narrative proposal plus allowlisted world/economy operations, records acceptance, then persists. The controller restores its previous in-memory state on thrown errors. `core/controller.mjs:869-900` exposes a parallel `applyMasterProposal(rawProposal)` entry point with validation and rollback.
4. `master/proposal.mjs` rejects unknown proposal keys, validates enums/IDs/ranges, constrains sourceRuleIds to IDs in the supplied context, requires citations for acquisition decisions and for damage/repair/sale, and applies narration/check suggestions as pending state. It does not make arbitrary raw character/combat edits available to the provider.
5. This is a meaningful boundary, but it is not zero authority: allowlisted `economyOperations` and `worldOperations` can alter campaign state and are persisted after controller validation. A matching sourceRuleIds value proves only that the ID appeared in context; source membership alone does not demonstrate that the cited rule semantically authorizes a specific effect. The proposal flow also accepts a defined acquisitionDecision against an existing pending request. Those effects rely on deterministic validation/executors, not on RAG as a state writer.
6. `rag/sourceSearch.mjs` combines verified rule-matrix entries with imported library matches; `rag/sourceAuthority.mjs` ranks TESTADO/IMPLEMENTADO rule rows above imported PDFs and sets the listed library precedence. `rag/lexicalSearch.mjs` reports retrieval grounding based on status and non-placeholder summary. RAG returns context/reference results; inspected code does not call repository.save or apply campaign events from RAG results.
7. Therefore, current source supports: RAG is an input/retrieval boundary; Gemini/Barbara submit a constrained proposal; GameController and local modules perform the actual mutation and persistence. It does not support the broader claim that every proposed economic/world effect is individually rule-grounded or that every proposal operation has end-to-end executed proof. That broader claim remains PENDENTE.
