## Cross-cutting mechanical, UI, data and certification findings

1. **Check result semantics are mostly detached from source actions.** `adjudicateMaskOfThePirateQueenCheck` stores success and failure; it only adds alert ticks on a fixed node allowlist (plus SororiNet intrusion flag). Most subsequent choices ignore success/failure, including the Krezo clue, Vault approach/Revah, Vandin's tasks, persuasion/evidence, Ryale, space subsystems and boarding. Only SororiNet choices use check-success conditions. The scene may display a check prompt, but an adjudicated failure often leaves the same “success” choice open. Build a source-indexed result matrix and tests proving each relevant success/failure/advantage/threat has the printed consequence; don't infer state from freeform model narration.
2. **Source mechanics need an explicit boundary.** The scene/master request is a prompt and proposed-action list; the player/GM adjudicates checks and controller methods mutate world state. Keep RAG and narration read-only. Rules-backed dice, damage, vehicle actions, clocks, credits, encounter outcomes, clues and NPC statuses must flow only through validated deterministic commands and idempotent persisted receipts. The generic published-action/controller ledger helps, but this audit finds no evidence that source-specific encounter/stat/vehicle effects are fully wired for SWE13.
3. **Cross-book integration is present but not an editorial pass.** The registry restricts the catalog to five adventures and selects EotE/MIXED; this doesn't demonstrate that other VTTs are preserved or that every EotE/MIXED rule is handled correctly by each scene. Test mode gating and state isolation with unaffected VTTs. Keep rules profile EOTE_CORE unless the source requires otherwise.
4. **Persistence and migration:** v1 migration remaps the old Ord Mantell start to Saleucami and retains canonical event history; tests assert JSON round-trips. New clue/objective/vehicle/hazard/outcome facts still need schema/migration definitions, invariant checks and controller reopen tests. The 500-credit retainer and reward receipts must remain idempotent on retries/restart.
5. **Current advertised completion is not semantic completion.** Metadata says all 3/3 episodes implemented; `implementation.boundaryNodeId` is null. The graph ends, but route reachability and `episodesImplemented` are not evidence of full page/branch/mechanical coverage. Keep editorial certification false and status PENDENTE until the open source items below close.
