## 2. Existing implementation surface (not certification)

`BEYOND_THE_RIM` is registered as `beyond-the-rim`, uses the EotE core profile, and declares episodes 1–3. It has 25 scene nodes: 11 Episode I nodes, 8 Episode II nodes and 6 Episode III nodes. It provides a source-tagged narrative/check/choice graph; check adjudication; a six-step Imperial exposure track and Yiyar chase lead; several encounter specs; a 0–30 minute Imperial deployment clock; rewards/archive functions; player tracker/status projections; and end-of-adventure world consequences. `publishedAdventureRegistry.mjs` connects these functions to the universal adventure adapter. `controller.mjs` exposes clock advancement and adapter operations. Tests exist for each episode, controller continuity, persistence, anti-spoiler epilogue, player epilogue UI, tracker/trail UI, adjudication, fail-forward, mobile UI, world aftermath, narrative effects and combat integration.

These paths demonstrate a substantial playable scaffold. They do not establish exact source-page coverage, correct mechanical profiles, all branch outcomes, a full run/reopen through every ending, or complete source-specific effects. The module currently carries only a generic `SOURCE` object (title/system/product code/user material), not page-level provenance for most nodes/checks/effects. Its `implementationBoundary` is null. The test filenames/evidence history are evidence of test existence, not source-to-effect proof; no tests were run as part of this read-only audit.
