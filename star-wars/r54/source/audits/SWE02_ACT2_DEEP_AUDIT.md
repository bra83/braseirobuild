## Audit standard

A behavior is not certified merely because a graph node, UI control, or helper exists. Certification requires the exact official page and branch to map to deterministic rules, a reachable controller/UI path, persisted state that survives reopen, and test evidence exercising the same branch. The source and existing records support targeted implementation in several areas, but no evidence set closes the entire Act 2 page/branch set. Every item below therefore remains **PENDENTE**.
