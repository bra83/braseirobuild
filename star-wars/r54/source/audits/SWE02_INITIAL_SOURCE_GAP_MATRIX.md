## Status key

- **Targeted / tested (reported):** a page-specific proof artifact names an executor and an existing test. This audit relies on the artifact; it did not rerun that test.
- **Partial:** some relevant scene, transaction, or mechanics exist, while one or more source branches, rules, profiles, or downstream effects remain unverified or missing.
- **Not certified:** code or a graph node may exist, but the current evidence set does not prove source-semantic coverage for the page/branch.
- **Reference only:** credits, setup, lore, or map art; this still needs content/source reconciliation if the completion criterion requires every book page.
