## Decision rule and result

Each source claim below is `PENDENTE` unless the recovered evidence binds the exact printed page and source detail to deterministic rules, a controller and usable UI, persisted state with save/reopen proof, and a named test. Existing checkpoint proof files and test results are useful leads, but their stated status is not upgraded here. A test filename or a published adventure node alone does not prove save/reopen. Consequently, several implemented paths remain `PENDENTE` under this strict evidence rule; that is a ledger status, not a claim that the code path is absent.

The tree has meaningful targeted SWE02 work: P238 ship operations; P239 Thwheek vehicle combat; P240 Nabat support; P241 Nyn/social actions; P242 selected New Meen outcomes; P243 escort and optional abstract militia; P244 custody of borrowed weapons. It does **not** establish complete Act 1 coverage. No Act 1 certification is supported by this audit.
