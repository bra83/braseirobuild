# Pacote de assets — Old-School Essentials VTT

Este pacote foi desmontado a partir das 10 imagens fornecidas.

- **676 assets individuais** em PNG, organizados por categoria.
- **57 folhas de assets** com células, espaçamento e rótulos.
- `manifesto_assets.csv` informa nome, arquivo, fonte, recorte e dimensões.
- Assets vindos dos quatro catálogos usam fundo transparente por remoção apenas do preto conectado às bordas.
- Artes extraídas das telas permanecem opacas para preservar mapas, texturas e ilustrações.
- Elementos repetidos foram mantidos quando pertenciam a fontes/variantes diferentes.

## Convenção de nomes

Os nomes descritivos foram usados quando a leitura era inequívoca. Em catálogos muito densos, os itens recebem nome estável por categoria e índice, preservando rastreabilidade no manifesto.
