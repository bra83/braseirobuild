# Tutor Clínico Android — build no braseirobuild

Código Android isolado em `tutor-clinico/android` (branch de desenvolvimento).
O APK debug é compilado em GitHub Actions pelo workflow `tutor-clinico-android.yml`.
Nenhum dado de paciente real deve ser enviado ao repositório ou usado no teste.
A versão 0.1 é somente um protótipo de testes, sem validação clínica, LGPD ou em dispositivo físico.
