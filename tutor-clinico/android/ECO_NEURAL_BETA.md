# ECO 0.10.0 neural beta

Local DistilUSE multilingual cased v2, Apache-2.0, pinned revision bfe45d0732ca50787611c0fe107ba278c7f3f889. ONNX INT8 ARM64, native runtime 1.22.0. Mean pooling + original learned dense layer + tanh + L2 normalization. Long input windows are averaged by token count; this is an ECO adaptation. The model is not clinically trained. Search and nearest prior within-session pairs are exploratory, not NLI or diagnosis. No embeddings or results saved; model files only. Source reviewed text takes precedence, no invented timestamps. No cross-patient retrieval. CI provisions actual weights and tests ranking in Portuguese; Android runtime and tokenizer parity require physical validation. Existing lexical/acoustic tools remain separate. No silent fallback. Limits 1200 segments, 500k JSON chars. No clinical use until validation.
