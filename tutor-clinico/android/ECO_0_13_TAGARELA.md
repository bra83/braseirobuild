## Chave permanente

O APK anterior foi assinado pela chave de debug gerada pelo runner. Não há chave privada antiga disponível neste repositório; não prometer upgrade retroativo. Exportar e conferir backup antes de qualquer desinstalação. A partir da primeira instalação assinada com a mesma chave, Android aceita upgrades com applicationId br.com.tutorclinico.offline e versionCode crescente. Guardar a chave e senhas fora do Git; configurar GitHub Actions secrets ECO_KEYSTORE_B64, ECO_KEYSTORE_PASSWORD, ECO_KEY_PASSWORD. Alias eco. Não fazer commit do keystore. Exemplo local: keytool -genkeypair -keystore eco-update.p12 -storetype PKCS12 -alias eco -keyalg RSA -keysize 3072 -validity 10000; usar a mesma senha de store/key em PKCS12. Configurar secrets pela interface do GitHub ou gh secret set. Chave pública/certificado pode ser auditado; chave privada não. Sem secrets, workflow publica apenas APK debug claramente nomeado, não atualizável garantido. Com secrets, publica APK estável e verifica certificado. Validar atualização física com dados fictícios.
