# ECO 0.11 listening beta

Adds user-started transcription foreground service (mediaProcessing Android 15+, dataSync older), anonymous session-local x-vector clustering using Vosk speaker model, human role assignment, per-segment override, collapsible panels, repetition review and measured real-time speed. No background microphone, no cross-session voiceprints, no inferred roles, no automatic rewriting. This is segment-level experimental diarization, not overlapping speaker segmentation; short and ambiguous segments remain unknown. Vosk adds compute time; toggle off for speed. Foreground service protects app switching but not process death/force stop; Android physical validation pending, especially locked screen, journal, audio removal, long sessions and speaker error rate. Current Whisper quality/latency still requires WER/RTF tests on A57. Neural semantic quality gate unchanged. Only fictitious material until validated.
